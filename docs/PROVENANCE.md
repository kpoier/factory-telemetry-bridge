# Source provenance

The initial repository was extracted from the locally tested `factory-telemetry-bridge_0.5.100.zip`, based on private local version 0.5.0. The archive SHA-256 and every extracted file hash are recorded in [source-manifest.json](source-manifest.json).

Version 0.5.100 adapted the original runtime to Factorio 2.1: profiler helpers, recipe categories, crafter inventories, fluid access and connections, normal-quality fluid-box volume, and a copied-world validation probe.

Version 0.6.0 retains those Lua implementations and the internal mod name, and adds packaging, setting translations, documentation and publishing tools. It does not claim a performance improvement.

The old private compatibility archive had no redistribution license. On 2026-10-29, the source owner, kpoier, confirmed that the mod was their own work developed with Codex and selected the MIT license for publication. The current repository and releases are distributed under the root LICENSE. The historical private notice describes the earlier archive, not the current release license.

No Factorio engine binaries, proprietary game assets, saved worlds or unrelated mods are included in this repository.
